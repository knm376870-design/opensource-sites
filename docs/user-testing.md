# 俄语星球真实用户验收方案

## 目标

确认中文用户能在手机或电脑上独立完成资源搜索、收藏和留学生兼职查找，而不是只证明页面能够加载。

## 参与者

- 至少 3 人；优先覆盖俄语初学者、俄罗斯留学生或正在寻找俄语相关工作的人。
- 不记录姓名、电话、账号、证件、学校或精确位置。
- 参与者可以随时停止，不需要提供放弃原因。

## 测试任务

1. 找到一个适合自己的俄语词典并收藏。
2. 找到一个留学生兼职平台，并说出页面上的一条风险提醒。
3. 找到报告失效资源的入口，但不必真正提交。

主持人只读任务，不提示按钮位置。记录每项是否完成、所需时间、错误路径和参与者原话的匿名摘要。

## 验收标准

- 3 名参与者均完成任务 1 和任务 2。
- 至少 2 名参与者完成任务 3。
- 每项任务中位完成时间不超过 90 秒。
- 不存在导致所有参与者失败的同一个阻塞问题。
- 发现的问题进入公开 Issue，并按严重程度排序后修复或说明暂缓原因。

## 记录方式

使用仓库的“5分钟用户测试记录”Issue 模板。公开记录只能包含设备类型、任务结果、难度和匿名反馈，不得包含个人身份信息。
